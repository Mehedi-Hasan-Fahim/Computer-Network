# Computer-Network

This repository contains a comprehensive collection of lab assignments, code samples, and resources for learning about computer networks. It is intended to support students and enthusiasts in developing a practical understanding of networking concepts through hands-on exercises and experiments.

## Contents

- **lab/**  
  Directory containing lab assignments and practical exercises demonstrating key networking concepts.

## Topics Covered

- Basics of computer networking
- Network simulation and analysis
- Client-server model
- Common networking utilities and tools

## Getting Started

1. Clone the repository:
   ```sh
   git clone https://github.com/Mehedi-Hasan-Fahim/Computer-Network.git
   ```

2. Explore the `lab/` folder for lab instructions and code samples.
